Reconnect a thread's agent from its header: a fresh agent process, the same history.

## What you get

- A **Reconnect** button in every thread header, next to the other header controls.
- It releases the thread's agent runtime and keeps the history, environment and settings.
- The next message starts a fresh agent, so MCP servers reconnect and pick up new authorization.
- While the agent is working, it asks before interrupting the turn.
